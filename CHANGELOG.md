# Changelog

| Version | Date | Notes |
|---|---|---|
| v0.5.0 | 2026-11-24 | `aiogotoconnect.sms`: calls to the sending number as events. `create_goto_sms(..., watch_calls=True)` polls GoTo's call reports (scope `cr.v1.read`) and `sms.on("call", handler)` receives one `InboundCall` per inbound call (caller, caller ID as untrusted data, start time, GoTo's outcome). Off by default; nothing from before switch-on; at-least-once, keyed on `call.id`. `status()` gains an optional `calls` key (`watching`, `error`); a refusal backs off to hourly and never touches the login. Python only for now: not yet in the Node package or on the setup page. |
| v0.4.0 | (in v0.5.0) | Never published on its own; first released in v0.5.0. New `aiogotoconnect.sms` (optional `[sms]` extra): `create_goto_sms(...)`, a Python port of `@oneofthegeeks/goto-sms` as a framework-free ASGI app with the guided setup page (v0.2.1), encrypted credential storage, `send()`, inbound via webhook or polling, STOP/START/HELP opt-outs, and the same HTTP contract and C1-C25 behaviours (see `docs/conformance.md`). `sms.message_log.list()` reads the message log (no text bodies) without reaching into `sms.core`; `sms.access_token()` hands the host the login's current GoTo token for other GoTo APIs. Existing modules are unchanged. |
| v0.3.2 | 2026-11-13 | SMS errors now say why: `GoToApiError` gains `error_code`, `detail` and `reference` from GoTo's JSON error body, and its message reads e.g. `SMS send failed with HTTP 403: UNAUTHORIZED - Forbidden access to phone number +1…`. Only those three fields are kept (capped at 200 chars), never the raw body. Prompted by an outage starting 2026-11-12 that logged only "HTTP 403". |
| v0.3.1 | 2026-10-18 | Call-quality polish from the first live G.722 calls: the preferred codec is pre-encoded while the phone rings (no more dead air after pickup), and 0.3 s of silence is appended after the message so the BYE no longer clips the last word in the far-end jitter buffer. |
| v0.3.0 | 2026-10-18 | G.722 wideband (pure-Python encoder, locked to an ffmpeg golden vector) and SDP codec negotiation: the INVITE offers several codecs and the payload is encoded with the one GoTo answers. **Breaking:** `call_and_play(codec=...)` is now `call_and_play(codecs=(...))`, default offer `("g722", "pcma")`; PCMU is `codecs=("pcmu",)`. |
| v0.2.0 | 2026-10-18 | Renamed package gotoconnect → aiogotoconnect (unofficial-client naming convention); no functional changes. |
| v0.1.0 | 2026-10-17 | First release: async OAuth/token layer, Messaging v2 SMS, SIP voice calls (REGISTER + digest INVITE, PCMA/PCMU RTP, UDP/TLS, retransmits, Route sets, cancel-safe hangup). 110 tests vs a strict fake GoTo server; live-smoked against real GoTo (answered call, remote hangup, voicemail delivery, confirmed BYEs). Known deferrals: CANCEL not retransmitted; no GoTo SIP-TLS endpoint found for these devices. |
